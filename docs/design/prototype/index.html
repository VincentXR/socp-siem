      交互与无障碍契约

      • 跳转链接为 body 首个可聚焦元素，直达 #main。
      • 命令面板在真实 input 上使用 role="combobox"，aria-activedescendant 指向当前项；输入法确认不选择页面。
      • 抽屉带焦点陷阱，关闭后焦点回到打开它的行；备注有未保存改动时阻止 Esc 关闭。
      • 动效遵循 prefers-reduced-motion，包括运行期变更。
      • 主题默认跟随系统并在系统切换时实时跟进；手动切换后记住选择，命令面板可恢复跟随系统。
      • 目标尺寸指针目标 ≥ 24×24（WCAG 2.2 AA）；移动端主操作 ≥ 44×44。
      • 状态不靠颜色单独表达：严重级别同时有文字标签与色带。
